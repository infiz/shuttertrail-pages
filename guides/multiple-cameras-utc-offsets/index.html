Multiple-camera guide

How to geotag multiple cameras with one GPX file.

Record one private GPS trail on iPhone while you shoot with every camera you carry. Afterward, use the same GPX file to match each body’s photos in Lightroom Classic.

Why one trail is enough

A GPX file records where your iPhone was at a series of exact times. Every camera photo also has a capture time. When the phone stays with the photographer and the camera clocks are accurate, one location timeline can serve photos from multiple bodies without Bluetooth pairing or manufacturer companion apps.

Before the shoot

  1. Set every camera to the correct local date, time, and time zone.
  2. Compare the clocks across all camera bodies and correct any visible drift.
  3. Start Shutter Trail before the first photo and keep the iPhone with the photographer.
  4. Take a reference photo of an accurate clock with each camera if you want an easy audit point later.

Record once while every camera shoots

Shutter Trail does not connect to a camera. It records the iPhone’s location independently, so switching bodies or using two cameras at the same time does not interrupt the trail. Use High Accuracy when consistent background coverage matters, then turn it off when the shoot ends.

Export one standard GPX file

After the shoot, create a Trip for the relevant time range and export it as GPX. You can use that same file for every camera represented in the Lightroom selection.

Match the photos in Lightroom Classic

Select photos from one camera or several, then choose Library → Plug-in Extras → Sync selected photos with GPX…. The free Shutter Trail plug-in reads the capture time and stored UTC offset for each photo before proposing the nearest GPX point.

Handle missing offsets by camera

If a photo has no embedded UTC offset, the plug-in asks what to use. You can apply the answer to that photo, to photos from the same camera, or to all remaining photos without an offset. This is useful when different camera bodies write different metadata.

Tip: Do not assume two camera clocks agree because their displays show the same minute. Even a small difference can matter when you move quickly, so compare seconds before an important shoot.

Review before adding locations

Check the matching summary for unmatched photos, missing offsets, or a camera clock that appears consistently early or late. Existing GPS coordinates are preserved by default and are replaced only when you explicitly choose to overwrite them.
