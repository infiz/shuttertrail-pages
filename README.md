# Shutter Trail pages

Public support, privacy, and terms pages for Shutter Trail.

Published with GitHub Pages from the repository root.

The site is available at <https://infiz.github.io/shuttertrail-pages/>.
Search-engine discovery files are published at `/robots.txt` and `/sitemap.xml`.

## Formatting

Install the Git hook once:

```sh
pre-commit install
```

Format and validate every tracked file:

```sh
pre-commit run --all-files
```
