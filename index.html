Lightroom Classic plug-in

A time-zone-aware workflow for Lightroom Classic.

Lightroom’s built-in GPX workflow uses one manual tracklog offset. The free, open-source Shutter Trail plug-in reads each photo’s stored UTC offset instead, helps with missing offsets, and lets you review matches before applying them.
